🇬🇧 English 
Welcome to the C# WinForms Calculator! This is a desktop calculator application built with C# and Windows Forms, focusing on core arithmetic operations with a straightforward event-driven architecture.

✨ Features
Basic Arithmetic: Supports addition (+), subtraction (-), multiplication (*), and division (/).
Interactive UI: Fully functional 0-9 number pad and operation buttons.
Clear Function: One-click clear (C) button to reset memory and display.
Memory Handling: Temporarily stores the first input and operation type while waiting for the second input.

🚀 Getting Started
Clone the repo:
git clone [https://github.com/erencyn/Calculator-WinForms.git](https://github.com/erencyn/Calculator-WinForms.git)
Open the Project:
Double-click the .sln file to open it in Visual Studio.
Run the App:
Press F5 to build and run the application.
